# nezam

## تفعيل شاشة القائد

1. إذا كانت شاشة القائد مفعّلة، شغّل `supabase-commander-layout.sql` ثم انشر `index.html`. عند التثبيت لأول مرة شغّل `supabase-commander-display.sql` قبل تحديث التخطيط.
2. من حساب المدير افتح **الرئيسية ← إعداد شاشة القائد**. اختر حساب العرض والصفحات الإدارية، ورتّبها وحدّد نمط عرضها. راجع المعاينة ثم احفظ.
3. سجّل الدخول بالحساب المحدد وافتح **شاشة القائد** من الرئيسية. جرّب حسابًا آخر للتأكد من أن الزر لا يظهر له، ثم جرّب تغيير الحساب أو اختيار **بدون مستخدم** لسحب الصلاحية.

يُخزّن إعداد الشاشة مستقلًا عن سجلات الصفحات. يتحقق الخادم من دور المدير عند تعديل الإعداد ومن هوية المستخدم المحدد عند فتح الشاشة. يظل ظهور محتوى الصفحات مرتبطًا بصلاحية القراءة، ولا تعرض الشاشة محتوى الصفحات المقفلة. تعرض متابعة المعاملات إحصاءات الحالة فقط.
