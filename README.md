# nezam

## تفعيل شاشة القائد

1. شغّل `supabase-commander-briefs.sql` قبل نشر `index.html`. عند التثبيت لأول مرة شغّل `supabase-commander-display.sql` و`supabase-commander-layout.sql` بالترتيب أولًا.
2. من حساب المدير افتح **الرئيسية ← إعداد شاشة القائد**. اختر حساب العرض والصفحات، وأضف موجزًا إداريًا حيث يلزم، ثم راجع المعاينة واحفظ.
3. سجّل الدخول بالحساب المحدد وافتح **شاشة القائد** من الرئيسية. جرّب حسابًا آخر للتأكد من أن الزر لا يظهر له، ثم جرّب تغيير الحساب أو اختيار **بدون مستخدم** لسحب الصلاحية.

يُخزّن إعداد الشاشة مستقلًا عن سجلات الصفحات. يتحقق الخادم من دور المدير عند تعديل الإعداد ومن هوية المستخدم المحدد عند فتح الشاشة. يعرض القائد البطاقات داخل الشاشة بحسب صلاحياته. تعرض متابعة المعاملات إحصاءات الحالة فقط.
