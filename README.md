# nezam

## تفعيل شاشة القائد

1. شغّل `supabase-commander-display.sql` مرة واحدة في محرر SQL الخاص بقاعدة المنظومة، ثم انشر تحديث `index.html`.
2. من حساب المدير افتح **الرئيسية ← إعداد شاشة القائد**. اختر حسابًا واحدًا من مستخدمي المنظومة، وحدد العنوان والبطاقات الإدارية التي تظهر ثم احفظ.
3. سجّل الدخول بالحساب المحدد وافتح **شاشة القائد** من الرئيسية. جرّب حسابًا آخر للتأكد من أن الزر لا يظهر له، ثم جرّب تغيير الحساب أو اختيار **بدون مستخدم** لسحب الصلاحية.

يُخزّن إعداد الشاشة مستقلًا عن سجلات الصفحات. يتحقق الخادم من دور المدير عند قراءة الإعداد أو تغييره، ومن هوية المستخدم المحدد وعضويته عند قراءة البطاقات الظاهرة. لا تُجلب بيانات من الصفحات الأخرى تلقائيًا.
