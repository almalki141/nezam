# موصل واتساب لمنظومة العملاء

خدمة مستقلة تعمل دائمًا وتحفظ جلسة WhatsApp Web خارج الموقع. الربط غير رسمي وقد يتوقف أو يتطلب مسح QR جديدًا.

## التشغيل المحلي الجاهز على جهاز أحمد

1. افتح هذا المجلد واضغط مرتين على `start.command`.
2. ستفتح نافذة Terminal وتعرض **رابط الموصل** و**الرمز السري**.
3. من Chrome الذي يفتحه التشغيل: ادخل المنظومة ثم «متابعة أعمالي ← واتساب QR».
4. ضع الرابط `https://localhost:8787` والرمز الظاهر، واضغط «حفظ واختبار» ثم «عرض QR».
5. امسح QR من واتساب واترك الجهاز ونافذة Terminal يعملان لاستمرار الرسائل المجدولة.

بيئة Node والمكتبات موجودة محليًا داخل `.runtime` و`node_modules` ولا تُرفع إلى GitHub. جلسة واتساب محفوظة في `.wwebjs_auth`، وبيانات الجدولة في `data`، وكلاهما مستبعد من Git. Chrome الذي يفتحه الملف مخصص لهذا الاتصال ويسمح بشهادة `localhost` فقط.

## التشغيل على خادم دائم لاحقًا

```bash
npm install
AUTH_TOKEN="ضع-رمزًا-عشوائيًا-طويلًا-هنا" \
ALLOWED_ORIGIN="https://nezam.mrrsal.com" \
PORT=8787 npm start
```

يجب نشر الخدمة خلف عنوان HTTPS دائم، مع قرص دائم يحفظ مجلدي `.wwebjs_auth` و`data`. لا ترفع هذين المجلدين إلى GitHub ولا ترسل `AUTH_TOKEN` لأحد.

بعد النشر: افتح «متابعة أعمالي ← واتساب QR»، أدخل رابط الخادم والرمز السري، اختبر الاتصال، ثم امسح QR.

## متطلبات التشغيل

- Node.js 20 أو أحدث.
- ذاكرة مناسبة لتشغيل Chromium.
- خادم يعمل باستمرار؛ إغلاقه يوقف الرسائل المجدولة.
- رقم WhatsApp Business مخصص يُفضّل ألا يكون رقمك الشخصي.
